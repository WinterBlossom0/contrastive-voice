# Plan for the second final evaluation (written before it is run)

Written on 2 October 2026, before the test split is evaluated with the reworked detector. The second final evaluation is run once, when the detector is frozen; until then every run evaluates train and validation only.

1. **This is the second look at the test split.** The first final evaluation ran on 2 October 2026 with detector configuration `32cdd86f3d6e` (test strict event F1 0.879). Its tables are kept in `docs/evidence_final_32cdd86f3d6e/`, and its entry stays in `models/final_evaluations.json`.
2. **Why there is a second one.** The first detector was nearly blind for a different speaker (1 of 15 injected cross-speaker edits flagged; a botched different-speaker clip scored 96 to 100). The detector was reworked for that reason: pause threshold, pitch-range measure, thresholds per direction, whole-clip flags. Only aggregate test numbers of the first run had been seen; no design choice in the rework used a test result. One constant (`PAUSE_PEAK_DB`) was chosen so that no baseline's pause threshold changes, which looked at the unedited audio level of all nine baselines, the two test baselines included.
3. **What is evaluated.** The code and constants of the staged project whose hash list is `project_sha256.txt` in the run; the detector is calibrated inside the run on train data only, and its configuration hash is recorded in `models/final_evaluations.json` before any test number exists.
4. **Headline number.** Same-recording regime (R1), test split, level 2 and level 3 edits: strict one-to-one event F1 with all predictions counted, whole-clip flags counted as false positives. Reported beside it: overlap recall, flag precision, false flags per minute on test nulls, the score ladder and score gates on the test split.
5. **Both final results are reported side by side.** The second does not replace the first.
6. **There is no third run.** Later changes to the detector are evaluated on train and validation only and are labelled as such.
7. **What is not held-out.** Validation speakers and the three check readers were inspected repeatedly during the rework; their numbers are development evidence. For a different speaker (R2) the only pair not used in the rework is the Greenman reading against the Reagan recording (one speaker pair, five edited clips).
